# Veranda Pottery public website draft

Frontend-only concept for the client preview.

## Included
- Light, earthy visual direction with no gradients or glow effects
- Navigation: About / Workshops / Invite us / Visit
- Upcoming / Previous workshop toggle
- Sliding workshop presentation with poster-style left panel and details on the right
- Workshop details modal
- Invite Veranda section for schools, cafés, teams and private events
- Location section with Google Maps embed and fallback visual
- Responsive mobile layout

## Notes
- This is intentionally frontend only. No booking database, admin area, payment confirmation or ticket generation is connected yet.
- Upcoming workshop dates are not fabricated. The two upcoming cards use workshop formats publicly promoted by Veranda and show "Next date TBA".
- Previous-workshop content is based on public information about Veranda's Farm to Table collaboration, GLAD Summer Camp appearance and New Gateway school visit.
- The Facebook CTA points to the public share URL supplied for the draft.

Open `index.html` in a browser to preview.
